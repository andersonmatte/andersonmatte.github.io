# <img src="https://img.shields.io/badge/Overview-Responsibility-0066cc?style=flat-square" alt="Visão geral"> Visão geral

- Responsabilidade: definir a identidade visual, o leiaute responsivo e os estados visuais da interface.
- Limite: CSS não controla regras de negócio nem autorização.

---

# <img src="https://img.shields.io/badge/Guidelines-Responsive_Design-blue?style=flat-square" alt="Diretrizes"> Diretrizes

- Os tokens globais do Design System GOV.BR e as variáveis `--lec-*` orientam cores, tipografia, espaçamento e foco.
- Seletores acompanham a estrutura e as páginas para evitar estilos genéricos com efeitos inesperados.
- Pontos de quebra em `960px` e `740px` adaptam cabeçalho, menu, formulários, tabelas e diálogos a telas menores.
- Estados de foco permanecem visíveis e `prefers-reduced-motion` reduz animações quando solicitado pelo usuário.
- Esconder um elemento por CSS nunca substitui as verificações de acesso realizadas pela API e por `Aplicacao.tsx`.
